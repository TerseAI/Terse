Create your first Terse project, generate helpers from your connected integrations, and deploy it.

## Tutorial

<Steps>
  <Step title="Install the CLI">

```bash
npm install -g terse-cli
```

  </Step>
  <Step title="Scaffold a project">

```bash
# TypeScript (default)
terse init acme-revenue

# Python
terse init acme-revenue --language python

cd acme-revenue
```
  </Step>
  <Step title="Test locally">

```bash
terse test --verbose
```

  </Step>
  <Step title="Deploy to Terse">

```bash
terse deploy
```

Navigate to the link provided to monitor your workflow.

  </Step>
</Steps>
