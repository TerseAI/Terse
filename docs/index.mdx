## How it works

Use the language control to compare the same workflow in TypeScript (`createJob`) and Python (`@app.job`). In Python, GitHub is wired with `TriggerConfig` until GitHub helpers exist in `terse_generated`; Slack still comes from generated helpers after `terse generate`.

<CodeGroup dropdown>

```ts index.ts
const client = new Terse()

await client.createJob({
    name: "Summarize PR and send slack message",
    triggers: [GitHub.onPROpened({ repo: Repos.TerseAI.Terse })],
    skills: [
      // Fine tune what agents have access to
      GitHub.skill({ repos: [Repos.TerseAI.Terse] }), 
      Slack.skill({ channel: SlackChannel.AllTerseInc })
    ],
    onTrigger: async (event: GithubPRInputEvent, Agent: TerseAgent) => {
      
        // deterministically call a tool
        const message = await Agent.tools.slack.sendMessage({
            channelId: SlackChannel.AllTerseInc.channelId,
            message: "New PR from " + event.sender.login + "!"
        })
        
        // Outputs are strongly typed
        const parentId = message.message_ts

        // Insert any prompt you want. Use helper to easily feed event as well.
        const prompt = `
          Summarize this PR ${event.formatForAgentRunner()}.
          Keep it short. Reply in a thread to the Slack message (thread parent ts: ${parentId}).
          Format the summary in Block Kit; include screenshots or diagrams from the PR as image blocks.
        `.trim()
        
        // Trigger the Agent with Github + Slack tools auto added
        await Agent.runAndWait(prompt)
    }
})
```

```python main.py
from terse_sdk import GithubInputEvent, SkillConfig, Terse, TriggerConfig
from terse_generated import Slack, SlackChannel, TerseAgent

app = Terse()

# From your Terse workspace (TypeScript’s terse.generated maps friendly repo names to these ids).
github_integration_id = "<github-integration-id>"
repo_id = 0

@app.job(
    name="Summarize PR and send slack message",
    triggers=[
        TriggerConfig(
            integration_id=github_integration_id,
            integration_type="github",
            config_type="github",
            config={
                "repositoryIds": [repo_id],
                "eventTypes": ["pull_request.opened"],
            },
        ),
    ],
    skills=[
        SkillConfig(
            integration_id=github_integration_id,
            integration_type="github",
            config_type="github",
            config={"repositoryIds": [repo_id]},
        ),
        Slack.skill(channel=SlackChannel.AllTerseInc),
    ],
)
def on_github_pr(event: GithubInputEvent, agent: TerseAgent) -> None:
    sender = (
        event.metadata.sender.login
        if event.metadata and event.metadata.sender
        else "someone"
    )
    message = agent.tools.slack.send_message(
        channel=SlackChannel.AllTerseInc,
        message=f"New PR from {sender}!",
    )
    prompt = f"""
Summarize this PR {event.formatted_content}.

Keep it short. Reply in a thread to the Slack message (thread parent ts: {message.message_ts}).
Format the summary in Block Kit; include screenshots or diagrams from the PR as image blocks.
""".strip()
    agent.run_and_wait(prompt, event)
```

## Key concepts

| Concept               | What it means                                                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Context as Code**   | `terse generate` compiles your connected integrations into generated helpers — no runtime discovery of IDs, channels, or lists |
| **Workflow**          | A TypeScript or Python automation with triggers, skills, and a handler, deployed via `terse deploy`                            |
| **Trigger**           | The event (e.g. `Attio.onRecordCreated()`) or schedule (e.g. `Schedule.cron()`) that starts a workflow                         |
| **Skill**             | An integration capability available to the workflow (e.g. `Apollo.skill()`, `Slack.skill()`)                                   |
| **Generated helpers** | Resource constants, trigger builders, skill constructors, and deterministic wrappers                                           |
