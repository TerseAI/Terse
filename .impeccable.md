# Terse — Design Context

## Design Context

### Users
Technical non-engineers: PMs, data analysts, ops people, growth engineers. They can read code and understand APIs but don't write production code daily. They use Terse to build AI background agents that automate their workflows (code reviews, release notes, project tracking). They're in a work context — seated at a desk, focused, executing a task. They want to feel competent and in control, not guided or hand-held.

### Brand Personality
**Refined, dense, professional.** Three words: precise, capable, quiet.

The interface should feel like a well-made tool used by people who know what they're doing. No fanfare. No onboarding cheerfulness. Confidence through restraint. Think: the kind of product that earns trust by making every interaction feel deliberate.

### Aesthetic Direction
- **Reference**: Vercel / Railway — developer infra aesthetic. Monochrome foundation, precise spacing, deployment-focused density. Dark by default.
- **Anti-reference**: Zapier / n8n — no consumer-friendly workflow builder energy, no "automate anything!" marketing speak, no node diagrams or drag-and-drop playfulness.
- **Theme**: Dark mode default (already set in codebase). Light mode support kept functional but dark is the primary experience.
- **Palette**: Terse brand uses teal (#2a8a8a) as primary, with yellow (#f5c542) and red (#e85a5a) accents. Neutrals should be tinted toward the teal hue — even 0.01 chroma toward hue 180 gives subtle cohesion.
- **Density**: Favor compact layouts with clear visual hierarchy over spacious "landing page" breathing room. Information should be immediately scannable.

### Design Principles
1. **Earn every pixel.** If an element doesn't communicate something, remove it. No decorative flourishes, no illustrative icons above headings.
2. **Quiet confidence.** The UI should feel stable and authoritative. Avoid anything that looks like it's trying to impress — let the capability of the product speak.
3. **Density over spaciousness.** Technical users read faster than casual users. Pack information tightly with clear hierarchy, not generous whitespace.
4. **Deliberate motion.** Animations should feel mechanical and precise — fast transitions (150-200ms), exponential ease-out, never bouncy or elastic.
5. **No consumer vibes.** If it looks like it belongs in a freemium SaaS targeting non-technical people, it's wrong for Terse.

### Typography
- Current: Satoshi Variable — acceptable for the brand but slightly too "friendly". Retain it for body text.
- Headings / labels should use tighter tracking and heavier weight to reinforce the dense, precise feel.
- No fluid type scaling in the app UI — fixed rem scales only.
