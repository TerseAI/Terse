# Security Policy

## Supported Versions

We always recommend using the latest version of Terse to ensure you get all security updates.

## Reporting a Vulnerability

Please report security vulnerabilities to security@useterse.ai.

## Self-hosting

If you're running Terse on your own infrastructure, see [SELF_HOSTING.md](./SELF_HOSTING.md#security-model) for the self-host threat model and operational boundaries.
